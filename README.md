Projeto de doutorado de Thiago Cavali pelo CPGEI (Programa de Pós-Graduação em Engenharia Elétrica e Informática Industrial) da UTFPR - CT (Universidade Tecnológica Federal do Paraná - Campus Curitiba) sob Co-orientação do Prof. Dr. Mauro Sérgio pereira Fonseca e Orientação da Prof. Dra. Keiko Verônica Ono Fonseca.
Etapas do Projeto:
- Criação da rede de teste (Mininet)
- Instalação e criação do app no controlador ONOS
- Conexão do app ao Banco de Dados MySQL
- Redirecionamento de um fluxo de dados baseado no par IP:porta do fluxo consultado no BD
- Simulação de um Sensor para identificação de ameaças
- Conexão do Sensor ao sistema
- Notificação do controlador sobre mudanças no status do fluxo
- Testes e plots.
